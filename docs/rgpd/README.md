# Protection des données personnelles

Ces documents aident chaque organisation qui utilise We MEAL à tenir ses obligations (RGPD et
lois nationales équivalentes). Ils décrivent ce que fait l'application ; les passages
`[entre crochets]` sont à compléter par l'organisation, responsable des traitements.

| Document | À quoi il sert |
| --- | --- |
| [Registre des traitements](registre-des-traitements.md) | Ce qui est collecté, pourquoi, combien de temps, qui y accède |
| [Sous-traitants](sous-traitants.md) | Les services externes qui reçoivent des données, et comment les couper |
| [Violation de données](violation-de-donnees.md) | Que faire, dans quel ordre, en cas de fuite ou de compte compromis |

Les réglages se trouvent dans l'application, page **Données personnelles** (administrateurs),
et les opérations serveur dans le [README](../../README.md#données-personnelles-rgpd).
